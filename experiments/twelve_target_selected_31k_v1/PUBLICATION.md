# Git publication scope

The implementation, input freeze, preservation and validation records,
[completed report](output/REPORT.md), all public panel score/metric/exposure
tables, rank and retrieval summaries, sequence order and comparison figures
are deposited. This is the already public human demonstration panel, not the
protected C1/C2/C3 test corpus.

Learned endpoint feature arrays and runtime caches remain local. Model weights,
raw residue embeddings, the pinned runtime image and the original panel are
dependencies identified in `INPUT_FREEZE.json`; their bytes were not changed
or copied into this experiment for Git publication. No scores were recomputed.

The panel's training exposure and exploratory status remain as documented in
the report. See the [repository inventory](../../DEPOSIT.md).
