# Active pre-acquisition manifest set v5

The sole acquisition-authorizing index is
`data/source_manifests/PREACQUISITION_INDEX_v5.yaml`.

It retains every v4 source decision and adds only the governance-bounded
Lambourne et al. 2026 human Y2H-v1 panel. The Nature source files, Zenodo
record 19118078 v2.1 code/input archives, and official IMEx study IM-30553
preview representations are frozen separately with provenance and hashes.

IM-30553 is curated but not integrated into IntAct services on 2026-08-04.
The preview is therefore a dated provider snapshot and is not represented as
IntAct Release 252. Nature assets are governed by CC BY 4.0 unless a separate
credit line applies; the Zenodo record is MIT; IntAct data are CC BY 4.0.

This set authorizes acquisition and a source-faithful pair-level semantics,
mapping, evidence-overlap, and contamination audit. It does not authorize use
of study outcomes as training labels, merging with Negatome, benchmark split
construction, model training, or universal-nonbinding claims. Integration must
return to governance.
