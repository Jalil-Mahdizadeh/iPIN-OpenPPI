# Git publication scope

The four-recipe human PPI study has completed training, development selection
and the C1/C2/C3 comparison. Read [results/RESULTS.md](results/RESULTS.md) and
[STATUS.md](STATUS.md). The startup text in the original `README.md` is retained
as a historical record, not the current lifecycle status.

Git includes the implementation, protocol, configuration and launchers;
qualification, selection and aggregate result records; the immutable training
and scorer code snapshots; the documented pre-fit amendment and unused initial
snapshot; and per-epoch summaries, event histories and completion records for
all 12 fits. This preserves the exact code referenced by the freeze manifests.

Protected test records/predictions, raw input sequences and matrices, learned
features, checkpoints, runtime locks and scheduler logs remain local. Their
manifests and hashes are retained. No models were fitted, selected or rescored
for publication, and no latent residue token is claimed to be a validated
physical interface. See the [repository deposit inventory](../../DEPOSIT.md).
