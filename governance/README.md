# Governance records

This directory is the durable source of project authority and scientific change control. Material decisions must not exist only in chat history.

- `START_MANIFEST_v1.yaml` freezes the initial authorization, scope, claim ceiling, platform, and first action.
- `decisions/` contains numbered decision records.
- `gates/` contains current gate state and immutable gate reports.
- `novelty/` contains the prior-art and claim matrix.
- `risks/` contains the living risk register.
- `licenses/` contains source terms and redistribution decisions.

Changes to the primary target, metric, split, calibration universe, production platform, or claim ceiling require a numbered blueprint amendment approved by the expert group.
