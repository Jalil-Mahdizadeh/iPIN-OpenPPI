# BioPlex published-release use note

Date: 2026-09-11. Work package: DEC-0048.

Source: [official interaction downloads](https://bioplex.hms.harvard.edu/interactions.php).
Citation: Huttlin et al., *Cell* (2021),
[10.1016/j.cell.2021.04.011](https://doi.org/10.1016/j.cell.2021.04.011).

The official page provides the published 293T/HCT116 networks, directed edges
and bait lists for download and asks users to cite the corresponding papers.
Its separate unpublished quarterly-release sections request no large-scale
mining publication before peer-reviewed publication. Those releases are outside
this work's allowlist and were not acquired. The 2021 published releases alone
are used for the research challenge.

No general open-data redistribution license or provider file checksums were
identified on that release page. Do not infer either from public accessibility.
Keep downloaded files and row-level projections local and Git-ignored; publish
only analysis code, source URLs, acquisition hashes/metadata and aggregate
results. This note is an operational provenance record, not legal advice or an
assertion that all possible downstream uses have been cleared.

The release page itself was snapshotted alongside the six data files; evidence
is in `artifacts/results/external_bioplex_challenge_v1/ACQUISITION.json`.
